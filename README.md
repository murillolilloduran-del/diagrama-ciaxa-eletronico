# Diagrama de Sequência – Caixa Eletrônico

Este repositório apresenta um diagrama de sequência UML desenvolvido a partir de um enunciado proposto em atividade acadêmica do curso de **Análise e Desenvolvimento de Sistemas**.

## Objetivo
Representar o fluxo básico de funcionamento de um sistema de caixa eletrônico, evidenciando a comunicação entre os principais componentes do sistema desde a inserção do cartão até a consulta de saldo do usuário.

## Descrição do Fluxo
O diagrama de sequência ilustra a interação entre os seguintes elementos:
- Usuário  
- Tela  
- Sistema  
- Banco de Dados  

### Fluxo principal:
1. O usuário insere o cartão no caixa eletrônico.  
2. A tela solicita ao sistema a autenticação do usuário.  
3. O sistema valida as informações junto ao banco de dados.  
4. Após a autenticação bem-sucedida, o usuário solicita a consulta de saldo.  
5. O sistema realiza a consulta no banco de dados.  
6. O saldo disponível é retornado e exibido ao usuário na tela.

## Ferramentas Utilizadas
- UML (Diagrama de Sequência)  
- Draw.io (Diagrams.net)  

## Observações
- O diagrama foi modelado integralmente pelo autor, com base no enunciado da atividade, sem reutilização de modelos prontos.  
- O projeto possui finalidade exclusivamente educacional e acadêmica.
